PROJECT DETAILS

MiniCRM Platform

A modern CRM platform with customer segmentation, campaign management, and AI-powered intelligence.

Overview & Summary

MiniCRM is a full-stack Customer Relationship Management platform featuring dynamic customer rule segmentation, automated campaign management, and AI intelligence. It integrates Google OAuth 2.0 and OpenAI to convert natural language into customer segment rules, auto-generate campaign messages, and process asynchronous data queues with Redis.

  • ✓ Frontend Stack: Next.js 14, React, JavaScript, Tailwind CSS.
  • ✓ Backend Stack: Node.js, Express APIs, JWT Authentication, Google OAuth 2.0.
  • ✓ AI & Queue Pipeline: OpenAI API (Natural Language Rules & Message Suggestions), Redis Asynchronous Task Queue.
  • ✓ Database: MongoDB for documents & campaign analytics.
